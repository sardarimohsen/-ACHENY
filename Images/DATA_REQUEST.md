
# High-Resolution Data on Demand

The images included in this repository or linked via Mendeley may be compressed or resized for efficiency. If your research requires the **original, uncompressed high-resolution images** (e.g., for fine-grained morphological analysis), we can provide them upon request.

### How to Request
To request the full-resolution dataset, please send an email to the corresponding author:

* **Contact:** [Your Name / Lead Researcher Name]
* **Email:** [Insert Email Address]
* **Subject Line:** ACHENY High-Resolution Data Request

### Please include the following in your email:
1. **Your Name and Affiliation** (University or Research Institute).
2. **Brief Description of your Project** (How you plan to use the data).
3. **Agreement to Cite:** A confirmation that you will cite the original ACHENY paper in any publication resulting from the use of this data.
